# pokemon-app

An app created in Expo that shows your favorite pokémons, a Pokédex, and a user account screen.

## Features
- View a list of all Pokémon (Pokédex)
- Mark and view your favorite Pokémon
- User account/profile screen
- Built with React Native + Expo for cross-platform support

## Requirements
- [Node.JS LTS](https://nodejs.org/es/)
- [Expo](https://docs.expo.dev/get-started/installation/)
- [Yarn](https://classic.yarnpkg.com/lang/en/docs/install/#windows-stable)

## Quick Start
After cloning the project, install dependencies:
```bash
yarn install
```

Then, start the project:
```bash
yarn start
```

## Project Structure
- `App.js`: Main entry, sets up navigation and context
- `src/`: Contains navigation, screens, components, and context

## Useful Scripts
- `yarn start`: Start the Expo development server
- `yarn android`: Run on Android emulator/device
- `yarn ios`: Run on iOS simulator/device
- `yarn web`: Run on web browser
